   ```bash

   npm install
   cp .env.example .env.local
   ```

TROUBLESHOOTING QUICK LINKS
================================================================================

❌ "NEXT_PUBLIC_SUPABASE_URL is required"
   → .env.local not found or empty. See step 4 above.

❌ Can't sign up (getting errors)
   → Check Supabase auth is enabled. Go to Authentication > Providers.
   → Email/password should be ON by default.

❌ Can register but can't log in (stuck on "pending")
   → You forgot to promote your email to super_admin!
   → Run the SQL UPDATE query in step 2 above.

❌ Dark mode not working
   → Hard refresh: Ctrl+F5 or Cmd+Shift+R

For more issues, see PHASE1_SETUP.md troubleshooting section.
